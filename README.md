# Healthcare Analytics SQL Project

## 📌 Project Overview
This project focuses on managing and analyzing healthcare data using SQL. It involves creating a relational database, designing tables, establishing relationships, inserting records, and performing analytical queries to extract meaningful insights from healthcare data.

The project demonstrates the practical application of SQL concepts in a healthcare management and analytics environment.

## 🎯 Objectives
- Create and manage a healthcare relational database.
- Establish relationships between tables using Primary Keys and Foreign Keys.
- Insert and manage healthcare-related records.
- Perform data analysis using SQL queries.
- Generate insights related to doctors, patients, appointments, departments, and revenue.

## 🛠️ Tools & Technologies
- **SQL**
- Relational Database Management System (RDBMS)
- SQL queries for data manipulation and analysis

## 📚 SQL Concepts Used
- Database and Table Creation
- Primary Keys and Foreign Keys
- Constraints and Indexes
- Data Insertion
- SELECT, WHERE, ORDER BY
- GROUP BY and Aggregate Functions
- Joins
- Subqueries
- Views
- Window Functions

## 📊 Key Analysis Performed
- Retrieve patient and doctor information.
- Analyze the number of patients assigned to each doctor.
- Calculate revenue generated by different departments.
- Analyze payment modes and billing information.
- Identify top patients based on total payments.
- Analyze doctor revenue using views.
- Rank top-earning patients across different cities using window functions.
